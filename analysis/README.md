# Analysis working files — 2026-09-02 .. 2026-09-08

Everything here was produced in a scratch directory under `/tmp`, which is cleared on reboot.
Copied into the repo so the work survives and so other agents can read it.

Start with `../KINETICS_CONTEXT.md` — it is the shared brief (goal, pipelines, objective, traps,
settled results, open questions). This directory is the evidence behind it.

## The scripts that matter

Run from the repo root with `.venv/bin/python analysis/scripts/<name>`. Most read
`Projects/<name>/output_data/kinetics_eval/logReplay_full.bin` (the mc_rtc routine log, which is
the *conversion input* and never changes when the observer is re-run) or a `results/<run>/`
directory.

| script | what it establishes |
|---|---|
| `rpecorr.py` | **Validated RPE harness.** Reproduces the pipeline's own numbers to three digits (0.595 vs the published 0.596), so any RPE analysis should start from this rather than a hand-rolled window. |
| `balance2.py` | The filter's centroid force balance, using the exact rotation `stateDynamics` applies. Found 147 N of net horizontal force at standstill. |
| `calib4.py` | Per-foot wrench tilt identified from single support, pooled per robot. Produced the `wrenchCalibration` values now in `rhps1.yaml`. |
| `verify.py` | Cross-checks that tilt against **mocap** attitude rather than the estimator's, and checks the centre of pressure (which is why only the force is corrected, not the torque). |
| `sensfloor.py` | Sensor noise floor from unloaded windows. Produced the identified `forceSensorVariance` / `torqueSensorVariance` now installed. |
| `extw_all.py` | Estimated perturbation wrench read from the replay bags against a known truth of zero. The 4.4x / 7.8x calibration result. |
| `cone.py` | Tangential/normal force ratio, measured vs visco-elastic prediction. The model demands ratios the ground cannot supply. |
| `compete.py` | Where the innovation goes during cone violation — anchor vs unmodeled wrench. |
| `yawtorque.py`, `yawtcorr.py` | RHPS1's foot yaw-torque residual and its correlation with yaw error. The strongest correlate found for the yaw deficit. |
| `yawdist.py` | Yaw RPE vs sub-trajectory length. Explains the RHPS1-vs-LongWalk yaw story as a 1 m-vs-10 m artefact. |
| `transient.py` | Sub-trajectories grouped by position in the recording. Shows the vertical RPE deficit is a start-up transient and yaw is not. |
| `ate.py` | ATE, posyaw-aligned. **Own implementation, not rpg's** — ordering is robust, absolute values should be regenerated by rpg before publication. |
| `biascmp.py` | Both estimators' gyro bias side by side. Refutes the bias explanation for yaw. |
| `degrad.py`, `feas.py` | Slippage degradation ratios and the per-category check against the acceptance criteria. |
| `objtest.py`, `sens.py` | Objective verification and the marginal value of a 10% improvement in each metric. `sens.py` is how the "translation is worth 168x less than yaw" problem was found. |

Dead ends are kept deliberately (`satcorr.py` and `satcorr2.py` — force-saturation slip detection;
`mucmp.py` — the Coulomb limit) so they are not re-attempted. See `KINETICS_CONTEXT.md` section 5.

## Other directories

- `overlays/` — every covariance overlay tested. `tuned_a1_posx30.yaml` is the **previous** tuning,
  the reference every comparison in the log is against; it exists nowhere else.
  `wrench_tilt.json` holds the identified per-foot rotations.
- `configs/` — full mc_rtc config trees used with `--observer-config` for opt-in A/B runs
  (`cal/` = the wrench calibration before it was installed; `mu0.8/`, `mufd/` = the Coulomb-limit
  experiment).
- `backups/` — pre-change copies of files that were **untracked in git** when edited:
  `kinetics_tune.py.bak` (before the per-category objective), `kinetics_tune.pre-slipguard.bak`
  (before the two exploit fixes), `ko.py.bak`, `.ko_cache.json.bak`, `KINETICS_CONTEXT.md.bak`.
- `logs/` — run logs under 60 KB. The multi-MB sweep logs were dropped as regenerable.

## Result directories worth keeping (in `../results/`)

| directory | what it is |
|---|---|
| `kinetics-lw/` | The 13-dataset search (255 trials). `best-overlay.yaml`, `report.md`, `study.db`, `trials.csv`, and `best-best/` + `best-base/` with the winner's and baseline's own evaluations. |
| `kinetics-flex/` | The 25-dimension follow-up adding RHPS1 flexibilities. |
| `kinetics-retuning/` | The earlier 12-dataset search. Its objective values are **not comparable** — scored on medians, pooled, before the exploit fixes. |
| `baseline-newmetrics-*/` | The installed configuration's own evaluation. `ko.py` reads it to build `scripts/.ko_cache.json`. |
| `PW_base-*`, `PW_cal-*` | The wrench-calibration A/B, 12 datasets. |
| `LW_GATE-*`, `LW_K4e4-*` | LongWalk with the previous overlay, and the HRP5P stiffness test. |
| `KANG_*`, `FLEX_*` | The ten-variant RHPS1 contact-model sweep. |

`trials.csv` in each search directory carries every trial's parameters **and** its per-dataset
ratios, so per-category metrics for any trial can be recovered without re-running it — that is how
the winner's table was produced while the search was still going.
